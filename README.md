![Flask](https://img.shields.io/badge/Flask-3.1.1-FF4B4B?logo=flask&logoColor=white)

This project implements a machine learning model to classify emails as spam or ham (not spam). It leverages natural language processing (NLP) techniques to extract features from email text and trains a classifier using neural networks.
